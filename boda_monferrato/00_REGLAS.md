# Reglas del proyecto (valen para Claude y para todos los agentes)

1. **Correo: solo borradores.** Nunca se envía nada. Únicamente la usuaria pulsa «enviar». Esto incluye Gmail y cualquier otro canal (WhatsApp, formularios web, etc.).
2. Los contactos que no estén verificados se marcan como tales.
3. Sin cifras inventadas: lo estimado se etiqueta como estimación.
4. Decisiones con coste o compromiso (reservas, pagos, firmas) las toma la usuaria.
